# 🧠 Student Mental Health Analysis

## 📌 Project Overview
This project focuses on analyzing student mental health data to identify patterns, trends, and key factors affecting stress and well-being. The analysis is performed using Python with data visualization techniques.

---

## 🎯 Objectives
- Analyze stress levels among students
- Identify relationships between sleep, anxiety, and stress
- Detect patterns and correlations in mental health indicators
- Generate meaningful insights using visualizations

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

---

## 📊 Exploratory Data Analysis
The following analyses were performed:

- Stress Level Distribution
- Gender-based Analysis
- Sleep vs Stress Relationship
- Outlier Detection using Boxplot
- Correlation Heatmap

---

## 📈 Key Insights
- Students with lower sleep duration tend to have higher stress levels
- Moderate to high stress is common among students
- Strong relationships exist between lifestyle factors and mental health
- Outliers indicate extreme stress conditions in some individuals
